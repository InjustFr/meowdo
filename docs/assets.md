Every visual and sound asset shipped with Meowdo, with its source and licence. No AI-generated images.

| Asset | Source | Licence |
|---|---|---|
| Cat, bongos, cosmetics, backdrops, paw icons | Hand-drawn SVG in `assets/vue/components/cat/CatSvg.vue`, `PawCheck.vue`, `EmptyState.vue` | Project code |
| Bongo sound | Synthesised at runtime with the Web Audio API (`composables/useSound.js`) | Project code |

| Icons | Lucide, `@lucide/vue` | ISC |

The cat is drawn in the spirit of "bongo cat" memes but does not reuse the original Bongo Cat artwork, whose licence is not open. Add any new third-party asset here **and** on the `/credits` page (`assets/vue/pages/CreditsPage.vue`).
